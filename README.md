# 📚 English AI Tutor

> 🚧 **Projeto em Desenvolvimento**

Aplicação web desenvolvida para auxiliar estudantes brasileiros no aprendizado da língua inglesa utilizando Inteligência Artificial Generativa.

O projeto simula um tutor virtual capaz de responder perguntas, ensinar vocabulário, explicar regras gramaticais, sugerir exercícios e adaptar as respostas ao nível de conhecimento do usuário.

Este projeto está sendo desenvolvido como parte dos meus estudos em Desenvolvimento Web, Integração com APIs e Inteligência Artificial, com foco na evolução contínua da aplicação e na implementação de novas funcionalidades.

# 🧠 Como funciona

O usuário escolhe seu nível de conhecimento (Iniciante, Intermediário ou Avançado) e envia uma pergunta para o tutor.

A aplicação organiza o histórico da conversa e envia todas as mensagens para um servidor integrado à Google Gemini API, permitindo que a IA gere respostas contextualizadas.

O tutor foi configurado para:

- Responder sempre em português;
- Fornecer exemplos em inglês;
- Apresentar pronúncia das frases;
- Exibir a tradução em português;
- Adaptar as respostas ao nível escolhido pelo usuário.

# 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/thaygab/english-ai-tutor.git
```

Instale as dependências do projeto:

```bash
npm install
```

Crie um arquivo `.env` com sua chave da API:

```env
GEMINI_API_KEY=sua_chave_aqui
```

Execute o servidor e acesse a aplicação pelo navegador.
